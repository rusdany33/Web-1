# Codelab Modul 3

Jalankan dengan:

```powershell
php index.php
```

Codelab ini melengkapi kemampuan anggota untuk meminjam dan mengembalikan buku sesuai instruksi Modul 3.

Output yang diharapkan menunjukkan status buku: `Ya` sebelum dipinjam, `Tidak` setelah dipinjam, lalu `Ya` setelah dikembalikan.
